# 돗가비 (Goblin's Mansion)

도깨비 저택을 탈출하는 1인칭 퍼즐 게임입니다. 지나온 방이 실시간으로 다시 이어 붙는 저택을 직접 만든 C++ 엔진 위에서 구현했습니다.
게임인재원 4분기 팀 프로젝트입니다. (2024.01.26 ~ 2024.02.22)

- **기술:** C++17, Win32, DirectX 11, ECS, nlohmann/json
- **역할:** 프로그래밍 팀장, 엔진 코어 · 게임플레이
- **결과:** 11번 방까지 플레이 가능한 상태로 마감

## 담당 구현

- **실시간 공간 재배치 (`SpaceSystem`):** 두 출구의 방향 차이로 방을 회전시키고, 출구가 맞닿도록 배치
- **이벤트 기반 시스템 분리:** `SpaceAssemble` / `SpaceReturn` 등 게임 이벤트로 시스템 간 직접 참조 제거
- **조건 기반 퍼즐 이벤트 (`EventSystem`):** 방문한 방, 트리거, 시선 레이캐스트 조건을 조합한 이벤트 56종
- **계층 Transform 계산, 게임 루프, 엔진 매니저**
- **JSON 씬 역직렬화와 World 전환**
- **플레이어 조작, 상호작용, 다이얼로그, 단서 노트, 일시정지 UI**
- **프로그래머 6명의 작업 분배와 일정 관리**

DirectX 11 렌더러(PBR, 그림자), 물리, ImGui 레벨 에디터는 팀원이 담당했습니다.

## 참고

용량 문제로 `Resource` 폴더(모델, 텍스처, 사운드 등)와 빌드 결과물은 저장소에 포함하지 않았습니다.
